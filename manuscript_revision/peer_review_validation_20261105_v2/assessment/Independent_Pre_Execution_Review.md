## 任務一：A／B 兩種 EV 定義

### 必要性與唯一允許差異

這項比較直接回答稿件已明示、但尚未量化的 benchmark 定義依賴，屬最小必要補充。取同一來源參數 p，使用相同頻率、各原始情景、準備成本、採購限制、庫存、可達性、變數型別及次目標：

- A：先逐情景計算 `U_sji = floor(min_r R_rs/a_rsji + 1e-10)`，再取 `U_A,ji = Σ_s p_s U_sji`。不要對該平均值額外下取整；整數 x 已自然反映其整數可行上界。
- B：先對四類原始容量與單位需求、完整效益係數 b 各自取同一加權平均，再依相同正分母與浮點規則推導 `U_B,ji = floor(min_r Rbar_r/abar_rji + 1e-10)`。只有 EV 的 U 產生方式不同；不要對 B 的 RP／WS 原始情景作修改。

`benefit` 兩臂都取同一個完整係數的均值，避免同時改變效益組合方式。準備成本與 β 等非情景欄位保持不變。B 禁止在求解後依有利結果重新選取 rounding、U 或 EV tie rule。

### 執行範圍及輸出

最小範圍是兩個頻率向量下的 mobile 基線，各做 A、B；legacy 基線可作不含庫存的對照。既有採購上限十案例之全部重跑不是回答此問題的必要條件；若要宣稱「所有已測上限仍成立」，就必須預先列出並逐一檢驗，不能用基線結果外推。

各臂列出 EV 輸入的四類平均係數／容量、A 和 B 的 U、整數 x 的有效上界、EV 原目標、所有 primary-EV-optimal 一階政策、每政策的 EEV、VSS 範圍及原次規則選中的政策。EEV 固定完整 y 和 n。主要 EV 最適集合採相同 10^-6 score 容差；該容差是數值準則，不是統計不確定區間。若未完整枚舉，必須把範圍稱為「已檢查政策範圍」。

### 預先承諾的證偽判準

- RP、WS 只依原情景模型，A／B 間必須相同至 10^-6。若改變，表示控制失敗。
- B 的 U 在 y=1 時由非負資源行已蘊含，在 y=0 時令 x=0；A 的 U 最多加入額外收緊。因此同其他輸入時 `EV_B >= EV_A - 10^-6`。反向嚴格差異應先按程式／輸入錯誤調查。
- EEV 與 VSS 沒有 A／B 的普遍單調關係。EV_B 增加不能解讀成真實情景效益增加。
- 「正 VSS 不依賴兩個 EV 定義」只有在兩個定義、兩個頻率下，完整 EV 最適集合的 VSS 最小值都大於 10^-6 才獲支持。任一包含零或反例都須保留並收窄原敘述。
- 即使 A／B 政策或 VSS 相同，也不能宣稱兩定義一般等價；結論限於實際檢查案例。

## 任務二：共享庫存、採購整數性、可達性的受控消融

### 最小受控設計

以同一 mobile 基線為每個頻率向量的共同母模型。EV 主報 A，B 已在任務一獨立比較；若把 B 也用於消融，必須分開標註，避免再捆綁比較。

| 臂 | 相對共同基線的唯一機制差異 | 必須保留 |
| --- | --- | --- |
| 完整模型 | 無 | 所有原始行與變數型別 |
| 移除共享庫存行 | 僅刪每情景 `Σ_j x_sjD <= N0+n` | 資本行、n、access、所有資源行、y/x 整數性 |
| 連續採購負對照 | 僅 n 改為連續非負；若含非整數資本比，去除整數預處理上界並使用 Kcap/Ccap | x 全部仍整數、共享庫存與資本行、access |
| 只允許 Tai O1 泵可達 | 僅 `A=(1,0)` | 其他全部一致 |
| 只允許 Tai O2 泵可達 | 僅 `A=(0,1)` | 其他全部一致 |

兩個頻率共十個母模型設定已足以識別這三種一因子差異及地理不對稱；無需自動擴張為全因子研究。若要報交互作用，則必須另行預先定義交叉設計。基線兩地均可達，簡單「刪除 access 行」只會重複完整模型，可作實作負對照，不能作有效可達性檢驗。

不可用 `fleet=None` 代表「只移除共享庫存」，因為現行 Runner 同時移除資本、採購與 access。不可把 n 和 x 一起放鬆後稱為採購整數性消融。不可因基線不活躍而事後調參以追求顯著效果；若需要 Drainage-only 等機制示例，必須另列為事先指定的假設層，所有成對臂保持相同該層輸入，並把結論限於該層。

### 採購整數性目前不可識別嚴格效益增量

這是設計中最容易誤解的地方。對任一連續 n 的可行解，x_sjD 及 N0 都是整數，故

`Σ_j x_sjD <= N0+n` 蘊含 `Σ_j x_sjD <= N0+floor(n)`。

把 n 改成 floor(n) 仍滿足資本約束與全部原行，主要效益相同；n 的最小化次目標還會偏好較小值。因此只放鬆 n，RP／WS／EV 的最優主要效益和 EEV 可達值集合理論上相同，原 lexicographic 選擇可取整數。這項負對照可驗證實作，**不能產生「採購整數性造成嚴格 VSS／RP 差異」的經驗結論**。

連續 n 的 primary-optimal 一階集合可能含無窮多個剩餘庫存值。不可只枚舉整數 n 然後聲稱枚舉了連續集合；可明確按 floor(n) 的等價類計算，因整數部署下每類具有相同 EV、原情景 recourse 與 EEV。若移除庫存行，n 與部署脫鉤，最小採購次目標選 n=0 是構造的直接結果，不能稱為節省採購的政策建議。

### 證偽判準與限制

- 移除庫存行後 RP、WS、EV 不得降低；若無嚴格增加，只能說該案例的最優值未受影響。
- 收窄 access 後 RP、WS、EV 不得提高，但 VSS、EVPI、EEV 不具有同樣單調規則。
- 只放鬆 n 出現超過 10^-6 的主要效益差異，先視為控制／實作異常；不接受把差異寫成機制發現。
- 每個臂核查同一份非目標輸入、目標／次目標順序、所有資源鬆弛、共享庫存用量、禁止地區零 Drainage，以及 EEV 固定 y/n。採購量、政策字串改變不能自動證明唯一最適政策改變。
- 每臂分別滿足其自身 `WS >= RP >= EEV`；移除行的模型只屬鬆弛 benchmark，不可聲稱其解可由實際庫存執行。

## 任務三：假設性雙地區最低部署

建議只加一個明確、可重現的情境，對每個原情景和每個地區施加

`Σ_i x_sji >= 1, for every s and each j in {Tai O1,Tai O2}`。

這要求每地在每個情景至少實際部署一個模型干預單位，不只是 `Σ_i y_ji >= 1` 的準備選項。以相同完整庫存模型對照原 m=0，兩個頻率各檢查 m=1；不引入人口權重、效益校準或任意百分比。Drainage 是泵、Barrier/Warning 是包，因此「一單位」是示範性的模型部署門檻，不是相同人數、保護量、服務品質、公平或政策標準。

這個限制須同步用於 RP、WS、EV 及 EEV；EV 架構保留同一 B0、Kcap、庫存及 access。新增下界後，原稿「零部署確保所有一階計畫具有可行 recourse」的理由不再成立。執行器必須能記錄 INFEASIBLE，不能直接把所有不最優狀態當軟體失敗。若 EV 政策在原情景無可行 recourse，報明 EEV 不可行／有限 VSS 不可計算，不以零值、空值刪除或重選有利政策掩蓋。

本特定 m=1 實例有一個無需求解的可行見證：兩地只準備 Warning（總準備 CU 11,000），每地每情景各部署一包，不購泵。最大資源用量在 Extreme 為 CU 4,200、labour 136、equipment 6、supply 30，低於 30,000／400／60／220。故情境整體可行，但這不豁免逐一檢查所選 EV 政策。

預定報告原／新 RP、絕對與相對 score 差、準備／採購、各情景兩地實際部署、EEV/VSS 及可行性。新增約束後 RP、WS、EV 不得超過原模型至 10^-6；不能預定差額必然正，不能把差額稱為真實公平成本。若某地任一情景部署仍為零，檢查失敗。若 m=1 結果只證明移除全部部署集中現象，結論限於此一假設門檻。

### 設計調整的判斷

主代理採用兩個頻率、兩個資本面板（原 2m HKD 與明示假設 6.5m HKD），每面板 F0 無庫存 → F1 各地複製庫存／連續 n → F2 共享庫存／連續 n → F3 共享庫存／整數 n，另有相對 F3 的只 O1／只 O2 可達分支。**這個 24-case 設計可接受。** 它比本審查最小五臂設計多識別一個「每地錯誤複製相同庫存」的結構反事實；不得稱 F1 是實際可行庫存。兩個可達性分支不互作嵌套比較，F2/F3 零差異按預期負對照解釋。高資本面板須始終標作預設假設，無論是否激活目標機制，均保留零差異。

coverage 改為只求 RP，k=0、1、2 與明確預期不可行的 k=6。**此縮減可接受。** 上文「同步用於所有 benchmark」的要求適用於聲稱計算該情境之 WS／EV／EEV／VSS 的情況；若本輪只報部署限制的 RP 機會成本，就不必額外計算那些資訊價值，但必須明說未做。k=2 是額外的假設強度對照，k=6 是不可行處理負對照，均不得升級成實測服務標準。Extreme 每單位最低 labour=42；雙地各六單位至少需 labour 504>400，故 k=6 的不可行預期有直接數學依據。

### 初次靜態複核的執行門：暫不通過
