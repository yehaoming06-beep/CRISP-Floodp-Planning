# Source access and checksums

`source_access.csv` combines 23 parameter/geography registry records, 307 final official-source records and eight PDF records. All 338 local registered archive hashes matched on 18 November 2026. `parameter_sources.json` is an exact metadata-only copy of the held original registry. The original CI01 source manifests remain alongside the final-60 event ledger.

These files contain official URLs, relative held paths, byte counts and SHA-256; they do not include raw source content, cookies or response headers. Held-path files are not selected into Git. A checksum establishes identity, not permission. Source-specific conditions and limitations are in [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md), [rights/access](../../audit/Data_Rights_and_Access.md) and [REPRODUCE](../../REPRODUCE.md#external-source-boundary).

The root numerical workbook contains author model assumptions/coefficients and is retained separately. Source reports provide context, not a validated physical cost/effectiveness calibration. No unique necessary numerical input was removed to reduce package size.
